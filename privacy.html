Политика конфиденциальности

Эта политика относится к приложению Hermes and OpenClaw Akim Drive. Владелец и контакт по вопросам доступа к данным: Аким Либов, libov.akim@gmail.com.

Доступ к данным Google

Приложение получает доступ только после согласия владельца соответствующего Google-аккаунта. В зависимости от предоставленных прав это могут быть письма и вложения Gmail, файлы и их метаданные на Google Диске, документы и содержимое Google Таблиц. Конкретный набор разрешений показывается Google при авторизации.

Для подключения Скаута к обработке входящих документов запрашивается чтение Gmail. Для аккаунта, работающего с таблицами, дополнительно запрашиваются доступ к Google Таблицам и чтение метаданных файлов. Права на отправку или удаление писем для этого подключения не запрашиваются.

Цели обработки

Данные используются для выполнения поручений владельца: поиска исходных документов, сопоставления и проверки сведений, разрешённых изменений рабочих файлов и подготовки результатов. Автоматизированные помощники обрабатывают данные в пределах этих задач. Изменения ограничиваются разрешёнными операциями и целевыми файлами.

Хранение и защита

Рабочие материалы и квитанции могут сохраняться в контролируемой владельцем инфраструктуре для проверки результата, защиты от повторного выполнения и восстановления. Доступ ограничивается уполномоченными пользователями и процессами. Разрешения Google и другие секреты хранятся отдельно от публичного сайта; для передачи используются защищённые соединения.

Сроки хранения зависят от задачи. Для документов учёта переводов принят срок три года после окончания соответствующего года. Владелец рассматривает запросы на удаление материалов с учётом сохранности необходимых рабочих записей и действующих обязательств.

Передача и доступ людей

Результаты могут передаваться только назначенным владельцем получателям и сервисам, необходимым для выполнения запрошенной функции, с его разрешения. Внутренние отчёты доставляются через согласованный транспорт; подробные сведения направляются только разрешённым получателям. Публичный сайт не используется для размещения этих данных.

Данные Google не продаются рекламным платформам или посредникам и не используются для персонализированной рекламы, оценки кредитоспособности или иных несвязанных целей. Приложение обязуется соблюдать Google API Services User Data Policy, включая требования Limited Use.

Отзыв доступа и запросы

Разрешение можно отозвать в настройках подключений Google. Это прекращает доступ по соответствующему разрешению, но само по себе не удаляет ранее сохранённые рабочие документы. По вопросам удаления, исправления данных и отключения приложения напишите владельцу по указанному адресу.

Публичный сайт

Эти информационные страницы размещаются на GitHub Pages. На них нет собственных форм сбора данных, аналитических скриптов и рекламных трекеров. GitHub может обрабатывать технические сведения о посещениях в соответствии со своей политикой конфиденциальности.

Изменения политики

При изменении целей использования или состава запрашиваемых данных описание и политика обновляются, а новое согласие запрашивается до использования данных новым способом.
