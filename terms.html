Условия использования

Hermes and OpenClaw Akim Drive — личное приложение владельца для внутренних задач ограниченного круга лично известных пользователей. Этот сайт содержит информацию о приложении; регистрация для неопределённого круга посетителей не предоставляется.

Разрешённое использование

Подключать можно только собственный Google-аккаунт либо аккаунт, от владельца которого получено соответствующее разрешение. Использование чужих данных без полномочий не допускается.

Права выдаются через Google и могут быть отозваны. Приложение выполняет только разрешённые задачи. Расширение прав, новые цели обработки и новые получатели требуют соответствующего согласования.

Результаты и изменения

Для рабочих изменений сохраняются источники и результаты проверки. При неоднозначностях, конфликте данных или неизвестном исходе зависимые действия удерживаются для разбора. Наличие отчёта о внесении данных в таблицу не является подтверждением исполнения операции внешним банком или иным сторонним сервисом.

Отключение

Владелец аккаунта может отозвать разрешение в Google и обратиться к владельцу приложения для прекращения обработки и разбора сохранённых материалов. Контакт: libov.akim@gmail.com.
